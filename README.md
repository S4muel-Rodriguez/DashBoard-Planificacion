# DashBoard-Planificacion

Diario de Trading: landing, inicio de sesión (usuario y contraseña) y dashboard con gráficos de barras y torta, calendario, análisis automático, importación desde Excel/CSV y exportación a Excel y PDF.

## Uso
Abre `index.html` en el navegador (o publícalo con GitHub Pages). No requiere instalación.

## Notas
- Las cuentas y las operaciones se guardan solo en el navegador (localStorage); no hay servidor.
- Para inicio de sesión con Google y datos en la nube se necesita un backend (por ejemplo Firebase o Supabase).
- No es asesoría financiera.
